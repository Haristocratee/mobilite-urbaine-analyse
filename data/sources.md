# Sources de données

## 1. Validations IDFM (Île-de-France Mobilités)
- URL : https://data.iledefrance-mobilites.fr/explore/dataset/validations-sur-le-reseau-ferroviaire-annee-2023/
- Format : CSV (~500 Mo)
- Télécharger dans `data/raw/validations_idfm_2023.csv`

## 2. Population INSEE par commune
- URL : https://www.insee.fr/fr/statistiques/fichier/2028582/ensemble.xls
- Format : Excel
- Télécharger dans `data/raw/population_communes.xlsx`

## 3. Aménagements cyclables
- URL : https://transport.data.gouv.fr/datasets/amenagements-cyclables-france-metropolitaine/
- Format : GeoJSON
- Télécharger dans `data/raw/amenagements_cyclables.geojson`

## 4. Contours communes (GeoJSON)
- URL : https://geo.api.gouv.fr/communes?geometry=contour&format=geojson&zone=idf
- Format : GeoJSON
- Télécharger dans `data/raw/communes_idf.geojson`
